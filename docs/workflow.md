# Workflow

This lab fork uses GitHub repository `Arno1235/local-studio`.

- Default branch: `main`
- Create one feature branch per change from the current default
- Conventional commits (`feat`, `fix`, `docs`, `build`, `chore`, …)
- Open a pull request; do not push directly to `main` or `dev`
- Do not put extra executables under `scripts/` (installer hooks only)
- Never commit `.env`, API keys, or GGUF weights
